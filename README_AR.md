# Call Recorder — مشروع أولي

هذا مشروع Android تجريبي بواجهة عربية لإدارة تسجيلات صوتية يختارها المستخدم.
**لا يسجل المكالمات الهاتفية تلقائياً**: تسجيل صوت المكالمات محظور أو مقيّد على كثير من أجهزة Android، ولا يمكن ضمان تسجيل الطرفين. لا تستخدم المشروع لتسجيل أشخاص دون علمهم وموافقتهم حيثما يلزم.

## البناء
- افتح المشروع في Android Studio أو بيئة متوافقة مع Gradle.
- استخدم JDK 17 وAndroid Gradle Plugin 8.6.1.
- ابنِ APK من مهمة `assembleDebug`.
- اختبر على جهازك قبل الاستخدام.

هذه نسخة بداية لإدارة الملفات الصوتية، وليست مسجّل مكالمات مكتملًا أو APK جاهزًا مختبرًا.
